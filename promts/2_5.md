ГЛАВНОЕ ПРАВИЛО

НИЧЕГО НЕ ИЗМЕНЯТЬ В ПРОЕКТЕ.

На этом этапе запрещено:

- изменять код;
- создавать или изменять миграции;
- менять БД;
- менять конфигурацию;
- устанавливать зависимости;
- запускать команды, которые меняют состояние проекта;
- создавать файлы внутри проекта, кроме одного итогового документа, указанного ниже;
- делать рефакторинг;
- исправлять найденные проблемы;
- начинать реализацию Phase 0.

Разрешены только:

- чтение;
- анализ;
- статический аудит;
- просмотр схем БД;
- просмотр существующих моделей/repositories/services/handlers;
- чтение тестов;
- безопасные read-only SQL-запросы;
- анализ git diff/status/log;
- запуск только read-only диагностик и тестов, если они гарантированно не изменяют состояние.

Если есть сомнение, изменяет ли команда состояние - не выполняй её.
