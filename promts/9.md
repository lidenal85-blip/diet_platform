## ЦЕЛЬ

Сделать сохранённый недельный план доступным для ежедневного использования:

1. Экран «Сегодня».
2. Экран «Мой план».
3. Отметки eaten / skipped / replaced.
4. Связь блюда плана с полным рецептом через meal_state.recipe_id.

Проверяй фактические CODE, DATABASE, TEST, GIT и RUNTIME.

## Критерий завершения C-3

Считаем этап готовым, когда пользователь может:

1. Открыть «Сегодня» и увидеть сохранённые блюда.
2. Перейти в «Мой план» и открыть план повторно.
3. Отметить блюдо как съеденное, пропущенное или заменённое.
4. Открыть полный рецепт блюда из плана.
5. Повторно открыть рецепт без новой генерации.
6. Сделать всё это после перезапуска бота, не теряя данные.

## Шаги C-3 (справочно, от владельца)

- **Шаг 1.** Сначала проверить текущую реализацию (планнер, meal_state/weekly_plans, функции чтения, клавиатуры/FSM, set_meal_status, сохранение рецептов и связь с блюдом плана, существующие тесты). Пока ничего не изменять.
- **Шаг 2.** Реализовать «Сегодня» и «Мой план»: чтение meal_state на текущую дату, действия ✅ Съел / ⏭ Пропустил / 🔄 Заменить / 🍳 Рецепт; отметки сохраняются в БД, не в FSM; «Мой план» — повторный просмотр активного плана по дням без регенерации.
- **Шаг 3.** Связать блюда с рецептами: «Рецепт» → найти сохранённый → если отсутствует, сгенерировать и сохранить → связать через meal_state.recipe_id. Повторное открытие — без новой генерации.
- **Шаг 4.** Обновить меню: Сегодня / Кабинет / Питание / Рецепты / Фитнес / Бюджет / Помощник. На этом этапе меняются только навигация и клавиатуры, необходимые для C-3.
